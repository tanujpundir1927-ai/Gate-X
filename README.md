# GateX – Smart QR Event Entry Management System
A full-stack QR-based Event Entry Management System built using Next.js, Node.js, Express.js, and MongoDB Atlas.

GateX is a full-stack QR-based event entry management platform designed to simplify attendee registration, pass generation, and entry verification.

The system generates a unique QR pass for every attendee, validates entries in real time, prevents duplicate access, and provides organizers with an admin dashboard for monitoring registrations and event analytics.

## Features

* QR Code Pass Generation
* Unique Serial Number for Every Attendee
* Real-Time QR Validation
* Duplicate Entry Prevention
* Admin Dashboard with Analytics
* Email-Based Pass Delivery
* MongoDB Database Integration
* Secure Admin Authentication
* Cloud Deployment using Vercel and Render

## Problem Statement

Manual event entry systems are slow, difficult to manage, and vulnerable to duplicate or unauthorized access.

GateX solves these issues through QR-based attendee verification, automated pass generation, and centralized event management.
